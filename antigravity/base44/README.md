# Base44

Build and deploy [Base44](https://base44.com) full-stack apps from Antigravity. The plugin teaches the agent the Base44 CLI and the Base44 JavaScript/TypeScript SDK, and how to troubleshoot an app in production.

## What you can do

- **Create and manage Base44 projects** with the Base44 CLI: configure entities, backend functions, realtime actors and AI agents, then deploy.
- **Build app features with the Base44 SDK:** read and write entities, call backend functions, use realtime actors and AI agents, add auth, and use the AI gateway.
- **Troubleshoot production issues** from backend function logs and workflow run history.

## What's included

- `base44-cli`: creating, configuring and deploying Base44 projects with the CLI.
- `base44-sdk`: building apps with the Base44 JavaScript/TypeScript SDK.
- `base44-troubleshooter`: diagnosing production problems from logs.

## Requirements

- A [Base44 account](https://base44.com).
- [Node.js](https://nodejs.org) and npm: the CLI runs as `npx base44 <command>` from your project.
